# Mentor match

1. Look in the city's own mentor list (`family.json`, `mentors`) for the field and her language.
2. If there is none, send `help.request` with the field to each sibling city. It travels through the country.
3. Sibling cities answer with `help.offer`: aliases, fields and languages only.
4. Intake introduces the mentor on the contributor's channel only after both agree.

Mentors are volunteers. Nobody pays for mentoring and nobody is paid.
